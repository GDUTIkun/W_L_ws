## Candidate task contract

The decision vector and 104 hard rows are unchanged.  Slack columns remain exactly zero in
the full hard matrix.  The soft rows are assembled in this order:

| Task | Rows | Physical residual |
| --- | ---: | --- |
| contact acceleration | 6 | left/right `[rolling,lateral,normal]`, `A*nudot + Adot*nu` |
| common rolling/base-X anchor | 1 | world-X base acceleration target; rolling coupling remains in the two contact rows |
| base height | 1 | world-Z base acceleration target |
| base orientation | 3 | world-axis angular acceleration target |
| leg posture | 4 | canonical left/right hip and knee acceleration target |
| wrench fidelity | 12 | left/right controller-FLU wrench residual |

Wheel angles are cyclic and therefore have no posture row.  For each side, contact-centred
wrench is shifted to the base-control-site origin and rotated into the body-aligned FLU
frame.  The frozen residual is

```text
W_feasible - W_reference - slack
```

so zero residual preserves `W_feasible = W_reference + slack`.  The equilibrium reference
is generated by solving the frozen 116-row zero-`nudot` hard problem; no old 36D vector is
copied or hardcoded.

For this local oracle only, task weights and slack penalty are all one, normalized-variable
regularization is `1e-6`, and physical scales reuse the 42D hard profile.  These are
exploratory algebraic values, not nonlinear tuning authority.

## Results

All seven declared gates pass:

- exact `42` variables and `104` hard rows;
- slack absent from every hard row;
- finite, symmetric positive-definite Hessian;
- all `32/32` frozen corpus problems independently solve, with maximum hard violation
  `4.441e-16`;
- equilibrium maximum `|nudot|=2.653e-4`, maximum `|slack|=4.738e-5`, maximum normalized
  wrench residual `8.291e-7`, and hard violation `8.327e-17`;
- all 54 positive/negative task-component probes move in the requested direction; minimum
  normalized response is `0.0308124`;
- named wrench shift/rotation and slack-sign residual errors are both zero.

Fresh v9 reproduces the same summary as v7/v8 after removal of one unused helper; the
validator and config hashes in the v9 manifest are authoritative.

## Decision

The 42D task assembly is accepted as the P21-T06 local candidate.  This does not freeze its
weights, gains, wrench/slack tradeoff, disturbance profile or outcome thresholds.  P21-T06
therefore remains `doing`, DG21-05 remains `OPEN`, and P21-T07/Core integration remains
blocked.  The next permitted work is a fresh 42D nonlinear runner with tuning/holdout
separation, per-task ablation/competition diagnostics and 10 s evidence.
