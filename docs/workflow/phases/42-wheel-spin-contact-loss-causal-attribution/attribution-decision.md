# Phase 42 Attribution Decision

## Classification

`P42-E_multiple_coupled_causes`

Three independently material observations are required to explain the frozen H0:

1. The tick0 fixed request/realization is not a rolling equilibrium, producing common physical
   `ddxi=-0.1202064 m/s²` before wheel rate exists.
2. Tick0 already contains material left/right contact asymmetry (`0.5366958 N` load and
   `0.1264461 mm` penetration difference); the right rate reverses sign by tick7 while the left
   remains negative, establishing a differential branch that a common-only explanation misses.
3. Zeroing only wheel rates with a freshly recomputed production WBC command changes pre-loss
   acceleration by up to `14.07469 m/s²` and load by `1.41770 N`, proving a later material
   rate-sensitive amplification channel.

No single P42-A/B/C/D classification survives the full evidence. A alone fails because the tick0
acceleration direction does not match the late positive common drift. B alone omits the already
material tick0 force/contact imbalance. C alone does not close the common-mode amplification. D is
not supported as unique because base/leg/wheel onsets are threshold-order-sensitive and the
wheel-rate intervention becomes strongly material. Reducing these contributions further would
require a manifold-changing or force-channel ablation forbidden by the frozen attribution
contract, so the quantified multiple-cause classification is the strongest supported result.

No rollout ablation was needed, and no repair is approved here.
