# Minimum-State Decision

Decision: **not reopened**.

The present evidence does not justify x16 retention, x18, or x24 implementation. Phase32's x24 is
still only a necessary observable superset. Because the gain-free isolation gate stopped this Phase,
normal hidden coordinates were not eliminated and mesh/spin mechanisms were not separated.

The narrow next experiment is an append-only coupled two-channel authority formulation with a
predeclared matrix-conditioning gate (rather than post-hoc gain tuning). If it cannot satisfy
wrench and bandwidth gates, the next model candidate must add only the evidence-required normal
coordinate/rate subset before considering wheel spin.
