# 拆机执行器力矩测试

测试对象：

```text
电机 + 减速器 + 驱动器
```

将其作为完整执行器模块拆下测试。

目的不是辨识电机内部所有参数，而是得到后续 **MuJoCo ↔ 真机动力学校准**最关键的三个执行器参数：

```text
① 静态力矩映射
② 执行器摩擦
③ 执行器等效转动惯量
```

---

# 1. 静态力矩标定

## 目的

确认：

$$
\tau_{cmd}
\rightarrow
\tau_{real}
$$

即控制器命令的力矩，在关节输出轴实际产生多少力矩。

## 装置

```text
固定执行器
    │
  输出轴
    │
刚性力臂 r
    │
Load Cell
```

力臂与测力方向尽量垂直。

实际输出力矩：

$$
\boxed{
\tau_{real}=Fr
}
$$

## 测试方法

依次给正负不同力矩，例如：

```text
-3 Nm
-2 Nm
-1 Nm
-0.5 Nm
0
+0.5 Nm
+1 Nm
+2 Nm
+3 Nm
```

每个点记录：

```text
τcmd
Iq
F
τreal = F·r
```

拟合：

$$
\boxed{
\tau_{real}
=
k_\tau\tau_{cmd}+b
}
$$

## 最终得到

```text
kτ       torque scale
b        torque bias
deadzone 小力矩死区
正负方向不对称
```

## 用在哪里

用于真机的力矩命令标定。

如果控制器希望输出：

$$
\tau_d
$$

则可根据标定结果反算实际发送的：

$$
\tau_{cmd}
=
\frac{\tau_d-b}{k_\tau}
$$

目标是使：

$$
\tau_d\approx\tau_{real}
$$

---

# 2. 执行器摩擦测试

## 目的

测输出轴内部的：

```text
启动力矩 / static friction
低速 Coulomb friction
```

主要用于后续动力学模型和惯量辨识。

## 装置

仍然使用：

```text
输出轴
  │
力臂
  │
Load Cell
```

关闭电机主动输出，使输出轴可以被外力拖动。

## 测试方法

### 2.1 启动力矩

从静止开始，非常缓慢地增加外力。

记录输出轴**刚刚开始运动**时的力：

$$
F_{start}
$$

得到：

$$
\boxed{
\tau_s=F_{start}r
}
$$

这表示 static friction / breakaway torque。

### 2.2 Coulomb friction

输出轴已经开始运动后，继续以非常低的速度匀速拖动。

记录维持缓慢运动所需的力：

$$
F_{drag}
$$

得到：

$$
\boxed{
\tau_c=F_{drag}r
}
$$

正反方向都做一次。

例如：

```text
正向：
τs+ = 0.45 Nm
τc+ = 0.30 Nm

反向：
τs- = 0.42 Nm
τc- = 0.28 Nm
```

## 最终得到

```text
τs+ / τs-    正反向启动力矩
τc+ / τc-    正反向低速 Coulomb friction
```

第一版模型可以取平均：

$$
\tau_c
\approx
\frac{|\tau_{c+}|+|\tau_{c-}|}{2}
$$

## 用在哪里

第一版摩擦模型：

$$
\boxed{
\tau_f
=
\tau_c\operatorname{sgn}(\dot q)
}
$$

进入关节动力学：

$$
M(q)\ddot q
+
C(q,\dot q)
+
G(q)
+
\tau_f
=
\tau
$$

后续也可以加入 MuJoCo，使仿真中的关节摩擦更接近真机。

# 3. 执行器等效转动惯量

## 目的

测：

$$
\boxed{
J_{actuator}
}
$$

即**不包含腿、轮子等外接部件时，从关节输出轴看到的执行器内部等效惯量**。

主要包含：

```text
电机转子反射惯量
+
减速器内部等效惯量
+
输出轴 / 法兰惯量
```

## 装置

拆掉：

```text
力臂
Load Cell
外接负载
```

使输出轴自由旋转。

## 测试方法

先完成前面的：

```text
静态力矩标定
+
摩擦测试
```

然后给执行器一个小的恒定力矩阶跃，例如：

```text
0 → +0.1 Nm
0 → +0.2 Nm
0 → +0.3 Nm

0 → -0.1 Nm
0 → -0.2 Nm
0 → -0.3 Nm
```

每次持续较短时间，避免输出轴转速过高。

记录：

```text
τcmd(t)
q(t)
dq(t)
Iq(t)
```

根据静态力矩标定得到：

$$
\tau_{real}
$$

再从编码器数据得到：

$$
\ddot q
$$

空载情况下近似：

$$
\tau_{real}
=
J_{actuator}\ddot q
+
\tau_f
$$

因此：

$$
\boxed{
J_{actuator}
=
\frac{\tau_{real}-\tau_f}
{\ddot q}
}
$$

## 加速度建议

不要直接对编码器位置连续差分两次。

可以选取阶跃后的一段近似匀加速区间，拟合：

$$
q(t)
=
q_0+\omega_0t+\frac12at^2
$$

得到：

$$
\ddot q=a
$$

每个正负力矩点分别计算一次 $J_{actuator}$，最后比较结果是否集中。

## 用在哪里

$J_{actuator}$ 用于补充机器人动力学中的执行器惯量。

可以直观理解为：

$$
J_{total}
\approx
J_{external}
+
J_{actuator}
$$

其中：

```text
Jexternal
= 腿 / 轮子 / 连杆等外部结构的等效惯量

Jactuator
= 电机 + 减速器内部的等效惯量
```

它主要影响：

$$
\boxed{
\tau
\rightarrow
\ddot q
}
$$

如果 MuJoCo 没有正确包含 $J_{actuator}$，就可能出现：

```text
相同 τ

MuJoCo：
加速很快

真机：
加速明显更慢
```

因此后续动力学验证中需要检查 inertia 和 dynamic coupling。

# 4. 最终测试顺序

```text
电机 + 减速器 + 驱动器
        ↓

① 静态力矩标定
τcmd → τreal
        ↓
kτ / bias / deadzone / 正负不对称

        ↓

② 摩擦测试
拖动输出轴
        ↓
τs / τc

        ↓

③ 空载加速测试
τreal → ddq
        ↓
Jactuator

        ↓

装回机器人
```

三组测试分别解决三个不同问题：

```text
静态力矩标定
→ 我命令 1 Nm，实际到底是不是 1 Nm？

摩擦测试
→ 执行器内部会吃掉多少力矩？

惯量测试
→ 剩余净力矩会产生多大的关节加速度？
```

这三项做完后，就可以把执行器作为一个基本已知模块，再进入整机的重力、COM、连杆惯量和动力学验证。
