# tools/analysis

## 目录职责

保存正式实验数据的清洗、对齐、拟合、PSD/频响、模型对比和报告生成脚本。

## 何时使用

当分析结果会进入 REVIEW、RECORD、模型参数或技术结论时使用。输入来自 `data/experiments/<run-id>/raw/`，派生结果写入同一 run 的 `processed/` 或 `figures/`。

## 维护规则

- 脚本必须显式指定输入 run、版本和输出位置，不能依赖未说明的本机路径。
- 分析不得覆盖 `raw/`；原始数据保持只读。
- 图和数值结论必须能回溯到输入数据、脚本版本和参数。

## 不适用内容

快速绘图和一次性观察可以放 `tools/scratch/`，无需建立完整数据包。
