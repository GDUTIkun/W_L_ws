# tools/scratch

## 目录职责

用于临时画图、小型 sanity check、一次性数据查看、快速测试和探索性脚本。

## 简化规则

这些工作**不需要**创建 `data/experiments/<run-id>/`，也不需要创建 Phase、PLAN、REVIEW 或 RECORD，只要不用于支撑正式技术结论。

- 输入可以是本地临时文件或已有正式数据；
- 输出写入被忽略的 `output/`、`results/` 或临时目录；
- 脚本可简短，但应避免覆盖原始数据或修改产品代码；
- 有价值、需要复现或将影响设计的结果，再提升为正式实验或 Phase 任务。

## 边界

“只是为了看一眼图、检查格式、确认一个小现象”属于 scratch；“要据此改模型、定参数、批准进入下一阶段”属于正式实验。
