# tools

## 目录职责

保存不属于产品运行时的工程辅助脚本，例如正式实验采集、离线分析、数据转换、文档检查、索引维护和轻量试验。

## 子目录

- [`experiments/`](experiments/README.md)：正式设计实验的执行、采集和回放。
- [`analysis/`](analysis/README.md)：正式数据的分析、拟合和报告生成。
- [`maintenance/`](maintenance/README.md)：链接、格式、数据转换和索引维护。
- [`scratch/`](scratch/README.md)：临时画图、小测试和探索；不要求完整实验流程。

## 允许内容

- 可复现的正式分析、实验和维护脚本；
- 轻量探索脚本；
- 小型命令行工具及其使用说明；
- README/Phase 链接检查、数据格式转换和报告生成入口。

## 禁止内容

- Controller、ROS 节点或 STM32 实时逻辑；
- 大型原始数据、生成报告和临时输出；
- 只有作者本机可运行、未说明依赖和输入输出的脚本。

## 上下游关系

脚本可读取仿真、固件或实验数据，但不能成为产品运行链路的隐式依赖。正式实验脚本与设计/Phase 记录的关系由 Graphify 保存和查询。

## 当前状态

目录当前为空，等待后续 Phase 添加真实、可复现的工程工具。

## 维护规则

- 正式实验和分析脚本说明用途、依赖、输入、输出和示例命令。
- scratch 脚本可保持轻量；只有需要复现或支撑结论时才补齐说明并提升。
- 输出默认写入已忽略的结果目录。
