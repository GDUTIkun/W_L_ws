# firmware/stm32/Hardware

## 目录职责

封装 STM32 与具体硬件外设、传感器和电机驱动器之间的访问逻辑，为 `App/` 提供稳定的板级接口。

## 允许内容

- CAN、I2C、IMU、电机驱动和时间/延时适配；
- 原始报文解析、设备状态和硬件量测读取；
- 与器件手册直接相关的寄存器定义。

## 禁止内容

- 机器人级任务编排和 ROS2 消息语义；
- MuJoCo 或主机仿真逻辑；
- 与某个上层控制器强耦合的策略判断；
- 自动生成 HAL/LL 源码的手工复制。

## 上下游关系

下游连接 STM32 外设、电机驱动器和 IMU；上游由 `App/` 调用，并向其返回原始或经过明确单位换算的设备状态。

## 当前状态

包含 CAN、电机、JY901S IMU、软件 I2C 和延时相关自研封装。

## 维护规则

- 明确每个量的原始单位、转换后单位、符号方向和有效范围。
- 硬件回调保持短小，不在中断中加入非必要阻塞操作。
- 设备协议变化必须由真实硬件或报文测试验证。
