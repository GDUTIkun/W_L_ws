# firmware/stm32/Math

## 目录职责

保存适合在 STM32 实时环境中复用的轻量数学、约束和 PID 工具。

## 允许内容

- 无硬件依赖的基础数学函数；
- 明确定义采样时间和单位的 PID 等局部控制工具；
- 数值边界、饱和和防积分饱和逻辑。

## 禁止内容

- 板级寄存器或设备驱动；
- ROS2、MuJoCo 或完整 WBC/NMPC 实现；
- 没有调用需求的预留算法框架。

## 上下游关系

由 `App/` 和 `Hardware/` 的自研逻辑调用，不应反向依赖机器人应用任务或具体外设。

## 当前状态

包含基础数学与 PID 实现。其参数不自动继承 Simulink 控制器参数，迁移时必须经过单独一致性和真机验证。

## 维护规则

- 保持函数确定性、低开销和显式边界行为。
- 新算法必须有可复现的输入输出测试。
- 控制参数的物理含义和采样周期必须在调用侧或 Phase 中记录。
