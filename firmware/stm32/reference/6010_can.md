## 4 通信协议及示例

## 4.1 CAN Simple 协议

默认通信接口是 CAN，最大通信速率 1Mbps（可通过 odrv0.can.config.baud_rate 读取和设置），出⼚默认速率 500Kbps。请注意：早期硬件版本（小于等于 3.7）中 USB 与 CAN 不兼容，请参见 3.1.8 中第 3)条，如何从 USB 切换到 CAN。

驱动器默认的协议即为 CAN Simple，如果用户切换到 CANOpen 协议，则需要通过下述指令切回 CAN Simple：

```txt
odrv0.can.config.protocol = 1 
```

请注意，在版本大于等于 3.10 的硬件版本上，通信接口同时支持 RS485，脉冲方向和PWM。通过下述指令确保通信接口是 CAN：

```txt
odrv0.config.comm_intf_mux = 0 
```

在电机精灵中，也可在通信参数中，切换物理接口以及 CAN 协议版本。

## 4.1.1 协议帧格式

## 4.1.3 CAN 协议实战


4.1.3.1 实战：上电校准



发送 CAN 消息的序列如下：


<table><tr><td>CAN ID</td><td>帧类型</td><td>帧数据</td><td>说明</td></tr><tr><td>0x007</td><td>数据帧</td><td>04 00 00 00 00 00 00 00</td><td>消息:Set_Axis_State参数:4对电机进行校准</td></tr><tr><td>0x007</td><td>数据帧</td><td>07 00 00 00 00 00 00 00</td><td>消息:Set_Axis_State参数:7对编码器进行校准</td></tr></table>


4.1.3.2 实战：速度控制



发送 CAN 消息的序列如下：


<table><tr><td>CAN ID</td><td>帧类型</td><td>帧数据</td><td>说明</td></tr><tr><td>0x00B</td><td>数据帧</td><td>02 00 00 00 02 00 00 00</td><td>消息:Set_Controller_Mode</td></tr></table>


江西伺泰威自动化设备有限公司


<table><tr><td></td><td></td><td></td><td>参数:2/2设置控制模式为速度控制,输入模式为速度斜坡</td></tr><tr><td>0x007</td><td>数据帧</td><td>08 00 00 00 00 00 00 00</td><td>消息:Set_Axis_State参数:8进入闭环控制状态</td></tr><tr><td>0x0D</td><td>数据帧</td><td>00 00 20 41 00 00 00 00</td><td>消息:Set_Input_Vel参数:10/0设置目标速度和力矩前馈,其中目标速度为10(浮点数:0x41200000),力矩前馈为0(浮点数:0x00000000)</td></tr></table>
