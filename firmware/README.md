# firmware

## 目录职责

保存机器人板级固件。当前实现位于 [`stm32/`](stm32/README.md)，负责传感器采集、电机通信、实时控制、安全保护和与上位计算平台的数据交换。

## 允许内容

- MCU 工程、板级驱动、自研实时任务和安全逻辑；
- 固件接口定义、协议实现和必要的板级配置；
- 能随源码复现的最小构建配置。

## 禁止内容

- ROS2 节点、MuJoCo 模型或主机控制器；
- IDE 构建输出、目标文件、固件二进制和临时日志；
- 未经 Phase 决策擅自固化的树莓派—STM32 生产协议。

## 上下游关系

上游是树莓派 Hardware Adapter 发出的控制命令；下游是电机驱动器、编码器和 IMU。固件向上提供关节状态、IMU、健康状态和安全状态。

## 当前状态

已有 STM32 工程及 UART2 二进制通信实验实现。UART2 当前是候选链路，不代表生产通信方案已经冻结。

## 维护规则

- 实时安全检查和力矩限幅必须留在 MCU/驱动器侧，不依赖 ROS2 实时性。
- 协议、单位、关节顺序或超时策略变更必须与 ROS Hardware Adapter 同步记录。
- 第三方库和生成目录不单独维护 README。
