# data

## 目录职责

保存正式设计实验或正式仿真批次的数据包。大型数据默认不纳入 Git；每个正式数据包的 README 保留在 Git 中，用于复现和追溯。

## 何时使用

只有需要可复现、可审查、会影响模型/参数/控制设计或 Phase 结论的实验才创建 `experiments/<run-id>/`。

临时画图、小测试、快速仿真和探索性验证不需要创建数据包；见 `tools/scratch/README.md`。

## 数据完整性

- `raw/` 是原始数据，采集后不手动编辑。
- `processed/`、`figures/` 是由脚本生成的派生内容。
- README 记录目的、方法、代码/模型版本、命令、时间、设备、输入、数据字段和结论链接。
- 小型且长期固定的回归向量不放这里，应放入其所属模型或测试目录。
